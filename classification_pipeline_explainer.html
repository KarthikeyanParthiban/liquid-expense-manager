🏛️ The 3-Tier Engine Breakdown

Engineered to deliver deterministic accuracy for known entities and statistical intelligence for uncataloged local merchants.

Tier 1 • Deterministic User Rules

User Rules Engine

Direct overrides configured by the user. If the user explicitly categorizes an unusual merchant (e.g. "Ramesh General Store" → Personal), Tier 1 intercepts the pipeline instantly.

  • ⚡ 0.05ms SQLite indexed lookup
  • 🔒 Complete user autonomy over categorization
  • 🎯 100% confidence override priority
Tier 2 • Heuristic Dictionary & VPA

500+ Brand & VPA Tokenizer

Deeply specialized dictionary covering Indian payment ecosystems. Deconstructs UPI VPAs (e.g. swiggy.rzp@icici) and disambiguates multi-vertical brands (Amazon Fresh vs Prime vs Retail).

  • 🍕 500+ Indian brands, fast food, utilities
  • 🔍 UPI gateway suffix stripping (.rzp, .payu)
  • 🛡️ Word boundary guards (\bjio\b vs ajio)
Tier 3 • On-Device Machine Learning

Subword N-Gram ML Model

Trained on character subword n-grams (3–4 chars) and word tokens. When an unknown local merchant arrives (e.g. "Sharma Sweet House" or "Gupta Kirana"), morphological subwords classify it accurately.

  • 🧠 Subword roots: kiran, medico, sweets
  • 📦 Zero native binary overhead (<800KB JSON)
  • 🚀 Sub-millisecond dot product & softmax
